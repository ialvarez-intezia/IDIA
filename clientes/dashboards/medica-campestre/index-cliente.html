05 · Recomendación de Intezia

Tres pasos, en este orden.

1Primero

Automatizar lo pendiente

Señalan Contenido y CRM como lo que aún falta automatizar. Proponemos empezar por uno de los dos, con un caso real de la dirección.

2Luego

Seguir con Claude Code

Piden dominar más Claude Code y programación. Proponemos seguir construyendo sobre sus propios procesos, con el mismo método de práctica en vivo.

3Después

Ampliar a las gerencias

Ven beneficio para el equipo directivo y para todas las áreas, y piden extender el conocimiento a direcciones y gerencias. Proponemos ampliar el piloto a esas direcciones.

Intezia recomienda avanzar en este orden y volver a medir con Edu-Trace al cierre de cada paso, con más respuestas, para confirmar con más datos esta primera lectura.
