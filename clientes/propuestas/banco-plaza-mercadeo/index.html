Banco Plaza ya tiene licencias de Copilot dentro de su ecosistema Microsoft, pero el equipo no le saca el máximo provecho. Mercadeo, en particular, ya entiende el potencial de Claude y está dispuesto a adquirir una licencia propia para su equipo.

Diagnóstico

  1. El volumen de creativos publicitarios que exige la operación mensual supera la capacidad actual del equipo.
  2. Las licencias de Copilot ya están adquiridas, pero el equipo no las usa como debería.
  3. Sin un proceso sistematizado de generación de creativos, cada pieza depende de capacidad puntual, no de un método repetible.
  4. El equipo ya entiende el potencial de Claude y está dispuesto a adquirir una licencia propia para este caso concreto.
  5. Bocetos, bases y llamados a la acción hoy se producen sin un proceso que el equipo pueda sostener por su cuenta.
