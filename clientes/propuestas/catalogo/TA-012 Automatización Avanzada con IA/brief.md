## Por qué este producto

*Arquitectura de flujos autónomos para la empresa moderna.* Este es el programa **más técnico** del catálogo: forma **Arquitectos de Automatización** capaces de construir sistemas que conectan aplicaciones, leen documentos (OCR + Vision multimodal), orquestan agentes autónomos y ejecutan procesos complejos sin intervención humana — con error handling estructurado, observabilidad y prácticas de producción reales.

## Diagnóstico (genérico de la audiencia técnica)

1. Procesos manuales y repetitivos consumen al equipo cuando podrían orquestarse en flujos autónomos.
2. Datos atrapados entre sistemas que no se hablan, ralentizando decisiones operativas y duplicando trabajo.
3. OCR de baja calidad sobre lotes documentales — extracción manual o errores costosos en producción.
4. Equipos técnicos sin acceso al estado del arte: agentes autónomos, MCP, multi-agent orchestration, Computer Use.
5. Automatizaciones sin error handling estructurado ni observabilidad — fallan silenciosamente y erosionan la confianza del negocio.

## Stack 2026 incorporado

- **Workflow engines**: **n8n** (self-hosted u cloud), **Make** (Integromat), **Activepieces** (open source), **Zapier con AI Actions**, **Pipedream** (code-first), **Microsoft Power Automate con Copilot**
- **IA multimodal y OCR**: **Vision API** en Claude 4.7 / GPT-4o / Gemini 2.5 (reemplaza OCR clásico para casos complejos), Docparser, Klippa, Rossum
- **Modelos frontier**: Claude 4.7 / 4.6 (excelente para razonamiento estructurado), ChatGPT GPT-5 / o-series, Gemini 2.5
- **Conectividad**: HTTP Requests · REST · GraphQL · WebSockets · gRPC · OAuth 2.0 / JWT / API Keys
- **MCP (Model Context Protocol)**: estándar Anthropic 2024+ para conectar agentes a herramientas y datos · ecosistema creciente de servidores MCP
- **Agentes autónomos**: **LangChain / LangGraph** (orquestación), **CrewAI** (multi-agent collaboration), **OpenAI Agents SDK / Assistants API**, **Anthropic Claude Code** (agente que escribe y ejecuta código), **Computer Use** (agentes que controlan computadoras), **Google Vertex AI Agent Builder**
- **Observabilidad**: logs estructurados, traces, métricas — Langfuse, Helicone, OpenTelemetry
- **CI-CD y robustez**: Git workflows, retries, circuit breakers, queues (Redis · RabbitMQ), versionado de workflows
