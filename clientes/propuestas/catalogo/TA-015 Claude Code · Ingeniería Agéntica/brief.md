## Por qué este producto

*Del autocomplete al ingeniero agéntico.* GitHub Copilot enseñó al mundo a aceptar sugerencias. **Claude Code enseña al mundo que un agente puede ejecutar el ticket completo** — leer la codebase, escribir el código, correr los tests, abrir el PR. La diferencia no es de grado: es de paradigma. Este bootcamp lleva al equipo de ingeniería del uso casual de Claude al dominio profesional: skills custom, MCP servers, sub-agents en paralelo, agentes propios con Claude Agent SDK y despliegue en CI/CD con spec-driven development.

## Diagnóstico (genérico de equipos de ingeniería)

1. Equipos usan IA solo para autocompletar líneas — **no han operado un agente real** (Claude Code) que ejecuta tickets completos.
2. Migrations, refactors masivos y debugging consumen días que un agente bien dirigido resuelve en horas.
3. Codebases grandes con onboarding lento de developers nuevos — el agente lee y comprende el repo en minutos.
4. Tareas repetitivas (PRs, code reviews, releases, changelog) sin automatización agéntica integrada al flujo.
5. Cada developer reinventa su propia configuración (CLAUDE.md, skills, hooks) — no hay plantillas compartidas en el equipo.

## Stack 2026 incorporado

- **Claude Code core**: CLI · VS Code Extension · JetBrains Extension · web (claude.ai/code) · Claude Code SDK
- **Modelos frontier**: **Claude Opus 4.7** (razonamiento profundo · tareas largas), **Claude Sonnet 4.6** (default · balance velocidad-calidad), **Claude Haiku 4.5** (sub-agents · tareas rápidas) · selección por carga cognitiva
- **Personalización**: **Skills** (skill registry · `~/.claude/skills/`), **Slash commands** (built-in + custom), **Hooks** (PreToolUse · PostToolUse · Stop · SubagentStop), **CLAUDE.md** (memoria contextual jerárquica), **Settings.json** y permisos
- **Integración**: **MCP (Model Context Protocol)** — servidores listos (GitHub, Linear, Notion, Slack, Google Workspace) y construcción de servidores propios
- **Orquestación**: **Sub-agents** para parallelización · **Background agents** · output styles
- **Construcción de agentes**: **Claude Agent SDK** — TypeScript / Python · file system access · web search · custom tools · skills as primitive
- **Producción**: GitHub Actions con Claude Code · spec-driven development · plantillas compartidas en equipo · observabilidad de costos (tokens · runs)
- **Adyacente**: Computer Use (control de browser) · Claude Code en pull requests · revisión asistida
