Copilot enseñó a aceptar sugerencias. Claude Code enseña que un agente puede shippear el ticket completo.

La diferencia entre un asistente que sugiere y un agente que ejecuta no es de grado: es de paradigma. Claude Code lee la codebase, escribe el código, corre los tests, abre el PR — y lo hace con personalización profunda (skills, hooks, MCP) y orquestación (sub-agents en paralelo). Este bootcamp lleva al equipo del uso casual al dominio profesional de la ingeniería agéntica.

Diagnóstico

  1. Equipos usan IA solo para autocompletar líneas — no han operado un agente real (Claude Code) que ejecute tickets completos.
  2. Migrations, refactors masivos y debugging consumen días que un agente bien dirigido resuelve en horas.
  3. Codebases grandes con onboarding lento — un agente lee y comprende el repo en minutos.
  4. Tareas repetitivas (PRs, code reviews, releases, changelog) sin automatización agéntica integrada al flujo.
  5. Cada developer reinventa su propia configuración (CLAUDE.md, skills, hooks) — no hay plantillas compartidas en el equipo.

02 · Objetivos

A dónde llevamos
al equipo de ingeniería.

Objetivo general

Capacitar a developers y equipos técnicos para operar Claude Code como agente de ingeniería profesional — desde fundamentos (CLI · IDE · Plan Mode · CLAUDE.md) hasta personalización profunda (skills · hooks · MCP · sub-agents), construcción de agentes custom (Claude Agent SDK) y despliegue en CI/CD con spec-driven development y plantillas compartidas en equipo.

Objetivos específicos

  1. Operar Claude Code en flujo diario: lectura de codebases grandes, refactor masivo, debugging asistido y code review con agente.
  2. Personalizar Claude Code: skills custom, slash commands propios, hooks (PreToolUse · PostToolUse · Stop) y sub-agents.
  3. Integrar MCP servers (GitHub · Linear · Notion · Slack · Google Workspace) y construir servidores MCP propios.
  4. Construir agentes custom con Claude Agent SDK aplicados a casos reales del equipo (TypeScript / Python).
  5. Desplegar Claude Code en CI/CD con GitHub Actions, spec-driven development, plantillas compartidas y métricas.

Modelo Intezia · Tres pilares

01

Tutoría activa

El facilitador no expone diapositivas — opera Claude Code en vivo sobre el repo del equipo y acompaña al developer en cada sesión hasta shippear el ticket / desplegar el agente / cerrar el pipeline.

02

Transferibilidad inmediata

Cada sesión se construye sobre el código real del equipo — no demos felices. Al cierre el equipo tiene CLAUDE.md, skills, hooks, MCP server propio, agente custom y pipeline CI/CD funcionando.

03

Curaduría de contenidos

Stack curado al estado del arte de Claude Code 2026 — Opus 4.7, Sonnet 4.6, MCP, Agent SDK, sub-agents — con énfasis en producción, costos y plantillas compartidas (no demos individuales).

06 · Beneficios del bootcamp

Lo que se llevan.

Perfil de egreso

  • Saber: domina la arquitectura de Claude Code y el paradigma agéntico vs autocomplete.
  • Saber hacer: opera workflows agénticos diarios, personaliza con skills/hooks/MCP, construye agentes custom y los despliega en CI/CD.
  • Saber ser: trabaja con disciplina de spec-driven development, controla costos y comparte plantillas con el equipo.

Beneficio del programa formativo

El equipo de ingeniería transita del autocomplete al ingeniero agéntico: opera tickets completos con Claude Code, despliega skills/hooks/MCP propios, construye agentes custom con el Agent SDK y los integra en CI/CD. Cada participante entrega un kit técnico de vanguardia listo para producción.
