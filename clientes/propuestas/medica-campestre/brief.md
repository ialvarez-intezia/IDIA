## Necesidad detectada

## Especificaciones del programa

- **Duración**: 12 horas académicas · 6 sesiones de 2 horas · **6 módulos** (uno por sesión).
- **Modalidad**: Online síncrono (mismo formato de la relación previa; ajustable a la
  plataforma del cliente).
- **Audiencia**: 2 personas — Jaime Rossetti (Director General) y Eduardo González
  (Presidente del Consejo). Piloto de validación, no volumen.
- **Currículo (6 módulos / 6 sesiones)**:
  1. Calibración con Claude (protocolo compartido de prompting avanzado).
  2. Claude Cowork (de la conversación a la ejecución).
  3. Primeros pasos en Claude Code (terminal + arquitectura del clon digital).
  4. Construcción del clon digital (primera entrega funcionando).
  5. Diseño de datos y dashboard del piloto (conexión a SAP, arranca la app de monitoreo).
  6. App móvil, iteración y entrega del piloto (cierre del programa).
- **Kickoff**: antes de iniciar sesiones, se levanta el perfil de ambos participantes y se
  define qué vistas/reportes del SAP entran a la primera versión de la app (la propuesta es
  el "abrebocas"; el diseño fino del proyecto se cierra en el kickoff).
- **Aliado**: ninguno.

## Decisiones de diseño

- Clonada de la capacitación canónica mono-fase `cumbre-andina/` (mismo `_base/styles.css`,
  misma asesora María Iribarren, sin roadmap multi-fase comercial: es un piloto de una sola
  fase, con una slide de visión estratégica que apunta a una fase futura sin cotizarla).
- **6 módulos / 6 sesiones** (uno por sesión, decisión explícita del usuario 2026-07-24 sobre
  la primera versión de 3 módulos): Calibración → Cowork → Claude Code (arquitectura del clon)
  → Claude Code (clon digital) → Claude Code (datos + dashboard del piloto) → Claude Code
  (app móvil + entrega). 16 slides de estructura estándar + 1 slide de visión estratégica = 17
  slides totales.
- **Clon digital reincorporado** (instrucción del usuario 2026-07-24): es la primera
  construcción con Claude Code dentro del programa; el piloto (app de monitoreo SAP) cierra el
  programa sobre esa base ya dominada.
- **Slide de visión estratégica** (nueva, antes de Propuesta Económica): reutiliza la
  estructura de `.s-goals` (caja destacada + lista numerada) — sin CSS nuevo, sin fechas ni
  cifras, encuadrada como invitación a una fase futura (auditoría → plan de reducción de
  costos → formación masiva), nunca como compromiso u oferta cerrada.
- Sin consultor nominado en Beneficios (Equipo INTEZIA Education, como en `meru/`): no hubo
  facilitador técnico mencionado por nombre en la llamada.
- Slide de Impacto reutiliza el set de estudios ya validado en el sistema (Stanford HAI AI
  Index 2026 · McKinsey State of AI 2025 · Anthropic Economic Index 2025), con hook adaptado
  al eje de programación/autonomía técnica.
- No se afirma que el hospital migra de SAP ni de ningún stack (§4.11): Claude Code se
  presenta como la herramienta que se integra a los datos que el hospital ya tiene en su SAP.
- **Tono despersonalizado** (feedback de sesión anterior): el deck evita dirigirse a "tú y tu
  Presidente del Consejo" (sonaba jerárquico/señalativo); usa "el equipo directivo" / "la
  dirección" / "ambos participantes" de forma consistente.
