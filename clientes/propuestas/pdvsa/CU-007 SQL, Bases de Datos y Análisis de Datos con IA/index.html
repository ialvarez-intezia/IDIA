SQL, Bases de Datos
y Análisis de Datos

Curso presencial de 20 horas que entrega autonomía técnica para consultar, transformar y analizar bases de datos relacionales, integrando la IA como copiloto de análisis.

Código: CU-007 PDVSA
02 / 12 “

Tienes los datos. Lo que falta es la autonomía para consultarlos y entenderlos.

Cada área genera y consume datos en bases relacionales y hojas de cálculo: gestión, planificación, finanzas, operaciones. Pero la capacidad de consultarlos directamente —sin pasar por intermediarios técnicos— sigue siendo un cuello de botella. Este curso entrega dominio progresivo de SQL combinado con IA como copiloto, para que cada profesional analice sus propios datos.

Diagnóstico

  1. Profesionales con responsabilidad sobre datos pero sin formación formal en SQL ni en bases de datos.
  2. Dependencia técnica para consultas básicas que ralentiza la toma de decisiones cotidianas.
  3. Análisis hechos en hojas de cálculo donde el rigor y la trazabilidad se pierden con facilidad.
  4. IA mal usada como "caja negra" para análisis sin verificación crítica de los resultados.
  5. Falta un entregable concreto que demuestre la autonomía adquirida (un dashboard sobre dataset propio).

02 · Objetivos

A dónde llevamos
al equipo.

Objetivo general

Desarrollar la capacidad técnica para consultar, transformar y analizar bases de datos relacionales mediante SQL —desde fundamentos hasta técnicas avanzadas— integrando la IA como copiloto de análisis y verificación, para reducir la dependencia técnica y acelerar la toma de decisiones informadas.

Objetivos específicos

  1. Comprender el modelo relacional, sus principios de diseño y normalización mediante el análisis de casos reales.
  2. Aplicar SQL esencial y avanzado para consultar, transformar y manipular datos de bases relacionales.
  3. Integrar la IA como copiloto de análisis (generación de SQL, EDA asistido, storytelling y dashboards) verificando críticamente sus resultados.

03 · Programa

4 módulos.

4 módulos · 5 sesiones · 20 horas académicas

I

Fundamentos de bases de datos relacionales

Comprende el modelo relacional, principios de diseño y configura el entorno técnico.

  • 1.1 ¿Qué es una BD?
  • 1.2 Modelo relacional
  • 1.3 ERD y cardinalidades
  • 1.4 Normalización 1-3FN
  • 1.5 Set-up del entorno
II

SQL esencial — consultas

Aplica SQL básico para extraer y agregar información de una base relacional.

  • 2.1 SELECT / WHERE
  • 2.2 ORDER / LIMIT / DISTINCT
  • 2.3 GROUP BY + HAVING
  • 2.4 JOINs
  • 2.5 Subconsultas y UNION
III

SQL avanzado y manipulación

Aplica técnicas avanzadas para consultas complejas, manipulación segura y rendimiento.

  • 3.1 CTEs
  • 3.2 Window functions
  • 3.3 CASE / COALESCE / cast
  • 3.4 DML + transacciones
  • 3.5 EXPLAIN, índices
IV

Análisis de datos con IA

Integra la IA como copiloto de análisis verificando críticamente sus resultados.

  • 4.1 Limpieza y nulos
  • 4.2 IA generando SQL
  • 4.3 EDA asistido
  • 4.4 Storytelling con IA
  • 4.5 Dashboards con copilotos

06 · Metodología

Aprendizaje
Basado en Retos

Modelo Intezia · Tres pilares

01

Tutoría activa

El facilitador trabaja codo a codo con cada participante: revisa código real escrito en el momento y depura en vivo, sin limitarse a exponer.

02

Transferibilidad inmediata

Cada sesión cierra con un reto sobre dataset realista. El mini-proyecto final usa un dataset propio del participante: lo que se practica en sala se aplica al día siguiente.

03

Curaduría de contenidos

SQL estándar (PostgreSQL como referencia) + prácticas modernas con IA. Sin redundancia académica, currículo revisado trimestralmente.

07 · Beneficios del curso

Lo que se llevan.

Perfil de egreso

  • Saber: comprende el modelo relacional y el rol complementario de la IA.
  • Saber hacer: escribe SQL básico y avanzado; usa IA como copiloto verificando resultados.
  • Saber ser: actúa con criterio crítico y respeta la integridad de los datos consultados.

Beneficio del programa formativo

Los participantes culminan con autonomía técnica para consultar, transformar y analizar sus propias bases de datos. Entregan un mini-dashboard funcional + resumen ejecutivo asistido por IA + un Query Book con sus consultas reutilizables.
