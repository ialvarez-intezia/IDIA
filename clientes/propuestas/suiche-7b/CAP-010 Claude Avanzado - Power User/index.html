No basta con conocer Claude. Hay que aprender a sacarle el máximo desde el principio.

La mayoría del equipo de Suiche 7B aún no usa Claude — o lo usa esporádicamente. La curva de adopción inicial sigue pendiente, y al mismo tiempo el sector financiero exige uso responsable y técnico desde el primer día. Este programa cubre ambas cosas en una sola formación: introducción esencial (interfaz, prompts, aplicaciones cotidianas) más profundización técnica (Projects, prompt engineering avanzado, Skills propias, gobernanza para banca). Del primer contacto al dominio medio-alto, sin saltarse los fundamentos.

Diagnóstico

  1. La mayoría del equipo aún no usa Claude o lo usa de forma esporádica — la curva de adopción inicial sigue pendiente.
  2. Quienes lo prueban se quedan en el chat básico — sin descubrir Projects, Files, Artifacts ni Skills.
  3. Sin marco común de uso, cada colaborador experimenta a su propio ritmo y nivel — la adopción institucional no avanza de manera consistente.
  4. La diferencia entre el uso casual y el uso técnico es enorme — instalar capacidad real exige cubrir ambos en una sola formación.
  5. El sector financiero exige uso responsable desde la primera sesión — no se puede aprender mal y corregir después.

02 · Objetivos

A dónde llevamos
al equipo de Suiche 7B.

Objetivo general

Llevar a los colaboradores de Suiche 7B desde el primer contacto con Claude hasta el dominio medio-alto — cubrir en una sola formación la introducción esencial (interfaz, prompts, aplicaciones cotidianas) y la profundización técnica (Projects, prompt engineering avanzado, Skills propias) con marco reforzado de gobernanza para sector financiero. La meta: instalar capacidad real desde la primera sesión sin saltarse los fundamentos.

Objetivos específicos

  1. Reconocer qué es Claude, sus modelos (Sonnet, Opus, Haiku) y configurar el setup óptimo desde el primer día.
  2. Operar la interfaz, escribir prompts efectivos con el framework INTEZIA y aplicar Claude a tareas cotidianas: correos, documentos, análisis y búsqueda.
  3. Construir workflows persistentes con Projects, Files y Artifacts — convertir Claude en parte estructural del rol, no en una pestaña más.
  4. Aplicar técnicas de prompt engineering avanzadas (XML, few-shot, prefilling, chain-of-thought) y diseñar Skills propias custom para Suiche 7B.
  5. Operar Claude con gobernanza reforzada para banca — privacidad, verificación crítica avanzada y marco común con criticidad operativa.
