04 · Cómo trabajamos

Así trabajamos con cada departamento.

Dos horas por departamento: armamos su Skill con un caso real y acordamos cómo compartirla.

  1. EntendemosQué cambia al pasar de un Gem a una Skill.
  2. ArmamosUna Skill con un caso real del departamento.
  3. ProbamosLa Skill con el equipo, midiendo el tiempo del caso.
  4. AcordamosCómo nombrar, compartir y mejorar las Skills.

Por qué en este orden Primero se entiende qué cambia; después se arma una Skill con un caso real; al final se prueba y se acuerda cómo compartirla.

Quién construye Cada departamento arma su propia Skill; Intezia guía cada paso, sobre casos reales de su trabajo.

Cómo funciona en la práctica

  • Qué es una Skill. Un paquete reutilizable de instrucciones, ejemplos y archivos que la IA aplica cuando el trabajo lo necesita.
  • Un caso real por departamento. Cada Skill parte de un caso real del departamento, que se elige en la reunión de arranque.
  • Decisión humana. Las Skills apoyan el trabajo, pero no deciden sobre personas: esa decisión queda siempre en el equipo.

Cómo cuidamos sus datos

Solo se usan datos que cada departamento autoriza compartir: no se cargan datos confidenciales ni personales sin su permiso.

ModalidadPresencial u online, según se acuerde en la reunión de arranque.
ParticipantesEl grupo que elija Zoom en cada departamento, desde el comité hasta el resto del personal.
Ritmo de trabajoSegún la disponibilidad de cada departamento, sin frenar su operación diaria.

06 · Retorno

Retorno esperado: tiempo recuperado con Skills.

No son cifras de Zoom: es el método con el que cada departamento calcula su propio retorno.

Cómo se calcula el retorno

  1. Caso realCada departamento elige un procedimiento que repite con frecuencia.
  2. Tiempo actualSe anota cuánto tarda hoy, con el equipo que lo hace.
  3. Con la SkillSe prueba la Skill en el mismo caso y se anota cuánto tarda.
  4. DiferenciaLa diferencia, por las veces que se repite, es el tiempo que se recupera.

Qué queda medido al cerrar

Caso

El procedimiento que eligió cada departamento.

Tiempo

Lo que tarda hoy y lo que tarda con la Skill.

Uso

Las reglas acordadas para compartir la Skill.

Hacia dónde va el proyecto

Skills compartidas

Lo que cada departamento arma se reutiliza en otros equipos de Zoom.

Más personas

El alcance se amplía paso a paso, del comité a toda la organización.

Criterio común

Zoom decide con evidencia cuándo conviene un Gem y cuándo una Skill.

Al cerrar, cada departamento de Zoom tendrá su propia Skill y el tiempo de su caso medido, lista para reutilizar.
