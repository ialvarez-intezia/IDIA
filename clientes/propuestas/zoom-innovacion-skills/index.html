04 · Cómo trabajamos

Así trabajamos con cada área.

Los Gems de seis áreas pasan a Skills de Claude y, después, Claude Fundamentals en las áreas priorizadas.

  1. RevisamosQué Gems tiene cada área, con Intezia o hechos después.
  2. MigramosCada Gem pasa a ser una Skill de Claude.
  3. AcordamosCómo nombrar, compartir y mejorar las Skills.
  4. ConocemosClaude Cowork, Artifacts, Projects y Code, en cada área priorizada.

Por qué en este orden Primero se revisan y migran los Gems de las seis áreas y se acuerda cómo compartir las Skills; después las áreas priorizadas conocen Claude con sus Fundamentals.

Quién construye Intezia guía la migración de los Gems que cada área nos comparte y, después, Claude Fundamentals en las áreas priorizadas.

Cómo funciona en la práctica

  • Qué se migra. Los Gems que cada área armó con Intezia y los que creó después, que el área nos comparte.
  • Claude Fundamentals. Cada área priorizada ve cómo Claude la ayuda en su trabajo, con Intezia como guía.
  • Decisión humana. Las Skills apoyan el trabajo, pero no deciden sobre personas: esa decisión queda siempre en el equipo.

Cómo cuidamos sus datos

Solo se usan datos que cada área autoriza compartir: no se cargan datos confidenciales ni personales sin su permiso.

ModalidadPresencial u online, según se acuerde en la reunión de arranque.

05 · Retorno

Retorno esperado: tiempo recuperado con Skills.

No son cifras de Zoom: es el método con el que cada área calcula su propio retorno.

Cómo se calcula el retorno

  1. Caso realCada área elige un procedimiento que repite con frecuencia.
  2. Tiempo actualSe anota cuánto tarda hoy, con el equipo que lo hace.
  3. Con la SkillSe prueba la Skill en el mismo caso y se anota cuánto tarda.
  4. DiferenciaLa diferencia, por las veces que se repite, es el tiempo que se recupera.

Qué queda definido al cerrar

Caso

El procedimiento que cada área elige para medir.

Tiempo

Lo que tarda hoy, para compararlo con la Skill.

Uso

Las reglas acordadas para compartir las Skills.

Hacia dónde va el proyecto

Skills compartidas

Lo que cada área migra se reutiliza en otros equipos de Zoom.

Más equipos

El alcance se amplía paso a paso, desde las seis áreas y las priorizadas.

Criterio común

Zoom decide con evidencia dónde conviene sumar Claude.

Al cerrar, las seis áreas tendrán sus Gems migrados a Skills, listas para compartir, y las áreas priorizadas conocerán Claude.
