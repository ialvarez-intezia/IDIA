01 · Visión general

¿Qué es este sistema?

Intezia Propuestas es una plataforma local que combina Claude (IA) con plantillas oficiales de marca para generar propuestas comerciales en PDF de manera consistente y rápida. Cada propuesta sigue la estructura aprobada por el CAO de Educación: portada, dolor del cliente, objetivos, programa, cronograma, evaluación (si aplica), metodología ABR, beneficios, cotización con campos editables, próximos pasos y cierre.

Diseña

Estructura curricular

Sigue los formatos oficiales de Intezia para Charla, Taller, Capacitación, Curso o Diplomado. Códigos, módulos, evaluaciones según corresponda.

Genera

PDF profesional

Slides A4 verticales con la marca oficial: paleta Intezia (negro, amarillo, naranja) y tipografía Graphit. Tres campos editables para que ventas escriba el monto.

Adapta

Por cliente

Cada propuesta vive en su propia carpeta dentro de clientes/propuestas/. Puedes archivar, editar o regenerar sin afectar otras.

Vende

Listo para enviar

El equipo comercial abre el PDF en Adobe Reader, escribe precio base y descuento, el TOTAL se calcula automáticamente. Listo para el cliente.

02 · Pre-requisitos

Antes de empezar

Necesitas tener instalado lo siguiente en tu Mac. Si ya lo tienes, salta al siguiente paso.

01

macOS reciente (10.15 o superior)

El sistema está optimizado para macOS. Funciona en Mac con Apple Silicon (M1/M2/M3) o Intel.

02

Editor de código (IDE)

Recomendado: Visual Studio Code. Descarga gratuita en code.visualstudio.com. También funciona Cursor, Sublime Text o cualquier editor que abra carpetas.

03

Claude (dos opciones — elige una)

La herramienta que conecta tu IDE con Claude. Hay dos formas de instalarla:

  • Extensión de VS Code (recomendado): abre VS Code → Extensions (Cmd+Shift+X) → busca "Claude Code" → Install. Sigue el botón de autenticación. No necesitas terminal.
  • CLI por terminal (alternativa): npm install -g @anthropic-ai/claude-code y luego ejecuta claude para autenticarte.
04

Obtener el proyecto Intezia Propuestas

Hay dos vías:

  • Vía 1 (recomendada para ventas): pídele el archivo .zip con todo el proyecto al administrador por correo. Lo descomprimes en tu Mac y listo, sin necesidad de GitHub.
  • Vía 2 (para perfiles técnicos): solicita acceso al repositorio privado en github.com/Isaac150305/intezia-propuestas y clónalo con git.

03 · Instalación

Setup la primera vez

Sigue estos pasos solo la primera vez que uses el sistema. Después no hace falta repetirlos.

01

Coloca el proyecto en tu Mac

Según la vía que elegiste antes:

  • Si recibiste el .zip por correo: descárgalo, descomprímelo (doble clic) y mueve la carpeta Intezia Propuestas a tu Home (/Users/<tu-usuario>/).
  • Si tienes acceso al repo en GitHub: en terminal, cd ~ y luego git clone https://github.com/Isaac150305/intezia-propuestas.git "Intezia Propuestas".
02

Abrir en tu IDE

En VS Code: File → Open Folder y selecciona Intezia Propuestas. Verás todos los archivos del proyecto en el sidebar.

03

Verificar dependencias técnicas

El sistema necesita Python con pypdf (para campos editables) y Google Chrome (para generar el PDF). Si la instalación es nueva:

  • python3 --version debe responder Python 3.x (viene con macOS).
  • pip3 install --user --break-system-packages pypdf instala la librería si falta.
  • Google Chrome debe estar en /Applications/ (descarga gratuita).
04

Activar Claude

Dos formas según cómo lo instalaste:

  • Extensión VS Code: abre el panel de Claude (icono en la barra lateral o Cmd+Shift+P → "Claude: Open"). Empieza a conversar directamente.
  • CLI: en terminal, dentro de la carpeta del proyecto, ejecuta claude.

04 · Uso día a día

Dos formas de iniciar una propuesta

Cuando llega un cliente nuevo, eliges entre subir un documento con la información o conversar directamente con Claude. Ambos funcionan; uno puede convenir más según el caso.

Modo A

Subir un documento

Ideal cuando…

Ya tienes un brief escrito, una minuta de la reunión con el cliente, un correo con todos los detalles, o un PDF/Word con el contexto completo.

Cómo: arrastra el archivo a la conversación con Claude o pégale el texto. Después escribe: "Genera la propuesta a partir de este documento".

Modo B

Conversación guiada

Ideal cuando…

El brief llegó por mensajes sueltos, recuerdas la reunión pero no anotaste todo, o vas a co-construir la propuesta sobre la marcha.

Cómo: escribe a Claude algo como "Quiero armar una propuesta para Empresa X". Claude te preguntará campo por campo lo que falta hasta tener todo.

Tip En ambos modos, Claude SIEMPRE pregunta primero: ¿Fundación o Educación? No se genera nada hasta que confirmes la división. Esto garantiza que el logo correcto vaya en el PDF.

Regla bloqueante

División Intezia Fundación o Educación. Define el logo y el tono.
Tipo de programa Charla, Taller, Capacitación, Curso o Diplomado.

06 · Flujo de generación

Cómo se construye la propuesta

Una vez que Claude tiene toda la información, el flujo es así (te lleva entre 1 y 3 minutos según el tamaño del programa):

1
Tú
Le pasas a Claude el brief o respondes sus preguntas hasta completar el checklist.
2
Claude
Verifica que la información esté completa. Si falta algo, te pregunta y se detiene.
3
Claude
Crea la carpeta clientes/propuestas/<slug-cliente>/ clonando la referencia de Cumbre Andina.
4
Claude
Adapta el contenido (programa, módulos, cronograma, datos del cliente, asesora) al tipo de documento elegido. No toca colores ni layout.
5
Claude
Ejecuta ./scripts/generar-pdf.sh <slug>: Chrome convierte el HTML a PDF y Python añade los 3 campos editables.
6
Tú
Recibes el PDF en clientes/propuestas/<slug>/propuesta.pdf, listo para revisar y enviar.

07 · Entrega al cliente

Cómo enviar la propuesta

El PDF que genera Claude tiene 3 campos editables en la slide de "Propuesta Económica" (página 8). Antes de enviar al cliente, ventas escribe el precio.

01

Abrir el PDF en Adobe Acrobat Reader

Es importante: usa Adobe Reader (gratuito, descarga en get.adobe.com/reader), no Preview de macOS. Adobe ejecuta el cálculo automático del TOTAL; Preview no.

02

Escribir Precio Base y Descuento

En la página "Propuesta Económica" verás dos rectángulos amarillos translúcidos. Haz clic en cada uno y escribe el monto. Formato libre: 2.250 REF, USD 4.200, etc.

03

El TOTAL se calcula automáticamente

El campo TOTAL (rectángulo amarillo sólido grande) se rellena solo: PrecioBase − |Descuento|. No tocarlo, es de solo lectura.

04

Guardar y enviar

Save As con el nombre del cliente (ej. Cumbre-Andina-Propuesta-Mayo2026.pdf) y envíalo por correo. El cliente verá los montos ya escritos.

Tip Si abres el PDF en Preview, los campos se ven y puedes escribir, pero el TOTAL queda vacío. Por eso siempre finaliza en Adobe Reader.
